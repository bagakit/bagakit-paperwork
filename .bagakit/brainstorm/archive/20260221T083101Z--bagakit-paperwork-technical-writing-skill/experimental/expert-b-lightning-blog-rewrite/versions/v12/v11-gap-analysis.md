# v11 Gap Analysis (for v12 Rewrite)

## 审计输入摘要

`v11` 已达可发布水位并可作为执行稿母版，但存在三项可改进点：术语轻微漂移、主稿中执行字段密度偏高、指标缺采样口径。

## 对照修复

| 审计点 | v11 表现 | v12 修复 |
|--------|----------|----------|
| P2 术语漂移 | 标题“专家评审系统”与正文“专家论坛”并存 | 全文统一为“专家论坛” |
| P2 主稿/执行信息混写 | 字段级门禁位于主干段落 | 字段表下沉到“附录 A（执行版）” |
| P3 指标口径不全 | 指标有名称但缺采样参数 | 新增“附录 B”定义对象、样本量、周期、阈值 |
| 内容偏短 | 关键段落解释较紧凑 | 增加机制解释和边界说明段落 |

## v12 验收清单

- [x] 术语统一（专家论坛）
- [x] 主稿保持叙述连续性
- [x] 执行约束下沉附录但未删除
- [x] 指标可复盘口径完整
- [x] 正文信息密度提升且不回退可读性
