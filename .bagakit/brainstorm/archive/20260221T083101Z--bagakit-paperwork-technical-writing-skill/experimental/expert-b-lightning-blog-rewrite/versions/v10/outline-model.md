# v10 Outline Model

## H1
- Brainstorm 的自解释系统与专家论坛评审系统

## H2 Blocks
1. 问题通常不是出在讨论现场，而是出在交接接口
2. 把讨论写成可执行记录，需要明确分工而不是增加文档数量
3. 专家论坛的作用是收敛争议，不是增加会议时长
4. 同一份主稿可以同时服务发布与执行，只要投影方式清晰
5. 结语

## Writing Controls
- 正文以段落为主，列表只用于并列且高密度信息。
- 每个 H2 至少有一个“机制解释段”，避免纯规则陈列。
- 删除口号化词组，优先具体角色、动作、验收信号。

- H2-3：流程图（门禁回路）
- H2-4：循环图（持续改进机制）
