# v11 Outline Model

## H1
- Brainstorm 的自解释系统与专家评审系统

## H2 Blocks
1. 真正的问题发生在交接，而不是讨论当下
2. 把讨论变成计划，需要稳定的文档接口
3. 专家论坛要输出可执行结论，必须保留字段级门禁
4. 对外发布稿和对内执行稿可以同源，但不能混写
5. 结语

## H3 Design
- 每个 H2 都有 H3 扫读锚点。
- 每个 H2 至少一段机制解释，不只给结论。
- 至少一个 H3 提供字段级执行约束。

## Audit-driven Fixes
- 删除发布稿内部迭代元数据。
- 恢复执行门禁硬信号。
- 提升 30 秒扫读可定位性。
- 弱化口号化开场与收束。
