# Version v6 Techniques

## Relative to v5: techniques added
- Introduced explicit rule for when to use bullets vs paragraph blocks.
- Rebuilt opening with a concrete handoff failure scene to increase human realism.
- Increased section-level information density by binding each claim to one operational consequence.
- Added more grounded before/after and checklist-style examples.

## Relative to v5: tightened
- Reduced abstract rhetorical phrasing.
- Tightened list usage to independent, high-information assertions only.
- Moved causal/relational content back into paragraphs.

## Intended effect
- Keep structure strong while making prose feel more human, concrete, and publishable.
