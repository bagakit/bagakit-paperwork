# v6 Outline Model

## Core hierarchy
- H1: one title
- H2: 4 modules (diagnosis / expression rules / convergence loop / rollout boundary)
- H3: 2~3 per H2

## Bullet vs paragraph rule
- Use bullets when:
  - each item is independent
  - each item has high single-sentence information value
  - order is non-causal
- Use paragraph when:
  - explanation needs causal chain
  - constraints or dependencies must be connected
  - counterexample/condition needs context
