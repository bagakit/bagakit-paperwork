## Techniques Applied

1. Problem-first opening:
   start from a concrete execution loss scenario, not abstract writing theory.
2. Mechanism triad:
   organize core body around `file contract + QA loop + expert forum validation`.
3. Paragraph-primary narration:
   keep long-form reasoning in paragraphs; use lists only for checkable constraints.
4. Publish/execute split:
   keep narrative in main body; place hard fields and metrics in appendix tables.
5. Evidence-bound flow:
   each major claim links to either a mechanism explanation, a process flow, or a gate.
