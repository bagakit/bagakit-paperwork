# v8 Outline Model

## H1
- Brainstorm 的自解释系统与专家论坛评审系统

## H2 Blocks (5)
1. 先定义读者和任务，不然“写得更好”只是空指令
2. 从“意见集合”到“决策接口”，中间差一条证据链
3. 专家论坛的价值，不是“讨论充分”，而是“收敛可执行”
4. 同一套内容如何同时适配“对外发布”和“对内落地”
5. 结语

## H3 Flow Pattern
- 每个 H2 按“判断 -> 机制 -> 案例/信号”展开。
- 至少 1 个模块包含反例压力段。
- 至少 1 个模块包含可量化验收信号（在第 4 块的第 3 小节）。

## Argument Order Contract
- 导航层：先告诉读者本节判断（结论先行用于导航）。
- 论证层：证据与机制先于局部结论（避免空结论前置）。
- 收束层：给行动与边界（可执行而非停在观点）。
