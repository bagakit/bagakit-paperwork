# Version v2 Techniques

## Relative to v1: techniques added
- Added failure-mode-first framing: explicitly listed recurring failure patterns before proposing mechanisms.
- Added explicit decomposition sentence: "这个问题可以拆成四个机制" to reduce cognitive jumps.
- Tightened term discipline: repeatedly used stable terms (`连续性/收敛性/验证性/交接性`) instead of rotating synonyms.
- Upgraded transition design: increased functional transitions (`因此/然而/如果/后续`) for clearer causal flow.
- Improved sentence rhythm: mixed long explanatory sentences with short control sentences to improve readability.
- Added boundary section: clarified scope and next work instead of presenting absolute closure.

## Why these changes
- To align with the reference article's engineering style: problem-first, mechanism-first, and operationally testable conclusions.

## Remaining gaps to evaluate with user
- Whether tone and precision now meet publication-level expectations.
- Whether section granularity is appropriate for long-form reading.
