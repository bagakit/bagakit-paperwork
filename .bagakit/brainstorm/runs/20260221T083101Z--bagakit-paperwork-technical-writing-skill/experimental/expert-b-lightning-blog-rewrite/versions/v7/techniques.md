# Version v7 Techniques (Structured)

## 1) 用词技巧（相对 v6）
- 标题词从抽象分类词改为读者问题句，降低“AI 模板腔”。
- 动词从“表达类”收紧为“执行类”（定义/约束/验证/回填）。
- 段间连接强化因果桥接，减少口号式转折。

## 2) 句子与结构控制（相对 v6）
- 列表只承载并列且可验收信息，因果内容回收到段落。
- 提升“长句解释 + 短句判断”的节奏对比，增强落点感。
- 收紧段落信息密度，减少“正确但无信号”的空句。

## 3) 行文思路（相对 v6）
- 先场景，再机制，再可执行接口，主线更稳定。
- 强化 `before/after` 最小案例，让抽象判断可感知。
- 结尾增加上线顺序与边界，避免停在价值判断。

## 4) 证据与验证（相对 v6）
- 提升“主张 -> 信号”绑定密度，每块都给可复核落点。
- 把“观点成立 + 工具可用”双验证写进正文表达，不只在流程说明中出现。

## 5) 预期效果
- 维持金字塔结构。
- 降低抽象和口号感。
- 提升可读性与可执行性的一致性。
