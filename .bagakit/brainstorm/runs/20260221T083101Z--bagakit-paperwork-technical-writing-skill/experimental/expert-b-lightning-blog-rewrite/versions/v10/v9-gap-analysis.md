# v9 Gap Analysis (for v10 Rewrite)

## 结论

`v9` 的结构和可执行性已经很强，但仍有明显的 AI 味信号：比喻偏口号、分点密度偏高、部分段落像规则宣读而不是自然叙述。`v10` 的核心任务是降模板感，而不是再扩规则数量。

## 对照问题

| 维度 | v9 观察 | 风险 | v10 处理 |
|------|---------|------|----------|
| 口号化表达 | 出现“返工机器”“接得住”类表达 | 读者容易感到生硬、套话 | 替换为具体场景与动作描述 |
| 分点比例 | 多处连续清单化表达 | 叙述节奏单一，像检查表 | 正文改为段落主导，清单只保留关键点 |
| 主体明确度 | 个别句子缺动作主体 | 可执行责任不够清晰 | 每段补“谁在做什么、如何验收” |
| 证据可感知性 | 有规则但实例偏少 | 读者难以形成实际画面 | 增加会后偏航与会议反例段 |
| 图文协同 | 有图但图后解读略短 | 图可能被当作装饰 | 图后补“图在解决什么问题”说明 |

## v10 验收标准

- [x] 删除高口号密度表达
- [x] 主要内容由自然段承载
- [x] 每个 H2 至少一段机制解释
- [x] 保留并强化三类图示的解释性
- [x] 开篇目标改为“理清思路 -> 可执行可回溯计划”
