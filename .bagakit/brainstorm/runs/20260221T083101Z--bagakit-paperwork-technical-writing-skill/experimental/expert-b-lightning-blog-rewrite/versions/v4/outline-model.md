# v4 Outline Model (Internal)

Model used (for writing process, not as reader-facing jargon):
- SCQA for opening arc: Situation -> Complication -> Question -> Answer.
- Pyramid for argument order: conclusion first, grouped supports second, evidence third.
- MECE check for body clusters: no overlap, no critical gap.

## Reader-facing outline
1. Why this matters now (problem pressure + consequence)
2. Where teams fail (3 failure modes)
3. What principle resolves it (one-line answer)
4. How the system is structured (4 modules with clear responsibilities)
5. How decisions converge (forum and evidence loop)
6. How completion is defined (handoff + archive conditions)
7. Rollout sequence (adoption order)
8. Boundary and next step

## Structure checks
- Heading count target: 7~9
- Each heading answers one question
- Each section: claim -> mechanism -> evidence cue
- No section should mix diagnosis and prescription without bridge sentence
