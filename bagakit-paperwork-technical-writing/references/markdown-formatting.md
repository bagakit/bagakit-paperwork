# Markdown Formatting Notes

## Mermaid

- Use `<br/>` for line breaks in node labels when renderer mode is uncertain.
- Keep node labels concise; move long explanation to text below diagram.

## GitHub Markdown

- In `.md` files, hard line breaks require explicit syntax (`two spaces`, `\\`, or `<br/>`).
- Keep a blank line before tables for stable rendering.
- Always use fenced code blocks with language hints.

## Structural readability

- Separate narrative paragraphs from checklist blocks.
- Keep one table focused on one review purpose.
