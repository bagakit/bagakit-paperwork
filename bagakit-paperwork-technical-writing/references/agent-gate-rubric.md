# Agent Gate Rubric

Use this rubric for quality checks that should stay in `Program Warning for Agent + Agent Gate`, not hard-fail rules.

## Dimensions (1-10)

- Execution clarity
- Trigger precision
- Standalone integrity
- Information architecture
- Publish suitability

## Decision

- approve: no P1 and thresholds met
- revise: any P1 or key threshold miss

## Finding Requirement

- Severity (`P1/P2/P3`)
- File and line anchors
- Impact + fix direction
