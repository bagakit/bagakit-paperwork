# Start Here

Use this sequence when writing with this skill:

1. `references/tpl/article-template.md`
- Build outline and first draft.

2. `references/writing-techniques.md`
- Apply technique stack before review.

3. `references/quality-gates.md`
- Check hard/warning gate expectations.

4. `scripts/check-article.py`
- Generate objective report and fix hard-gate issues.

5. `references/tpl/execution-appendix-template.md`
- Add operational and verification details.

6. `references/tpl/review-report-template.md`
- Record deltas, evidence, and remaining risks.
